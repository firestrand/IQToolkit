# Vector abstraction private compile experiment

This extends the required [source interoperability discovery](modernization-vector-interoperability-probe.md) to an isolated API-consumption experiment. The question is whether VectorData10.10.0 and the inspected stable PgVector1.0.1/Qdrant1.0.0 packages resolve together and compile the required caller-supplied collection/search/CRUD/native-extension surfaces alongside the unchanged IQToolkit assembly. A green compile would establish that finite API combination only. It would not implement a mapping bridge, settle a public contract or certify engine semantics.

## GOTCHA scope

**Goal:** Reduce mandatory vector interoperability risk before duplicate retrieval contracts. **Objectives:** Acquire the complete exact candidate dependency/source/license profile, bind existing public APIs using caller arguments only, generate and independently review the actual dependency graph, then perform a separate cold locked strict rebuild and preserve its real compiler/PDB evidence.

**Tasks:** Fresh readiness; official package metadata; private templates/controller preparation; expanded plan and independent planning/source/command reviews; isolated graph generation; observed graph review; separate locked rebuild; observed/integrated review and ATLAS. **Trigger:** Accepted VP0 source-only result leaves package/API coexistence unverified. **Termination:** Actual graph/compiler evidence or a preserved bounded failure, with no runtime/provider/support promotion.

**Capabilities:** Official HTTPS metadata and reviewed private .NET compiler operations. **Off-limits:** Driver/client construction, running bindings, enumerating results, service/schema/record/vector/embedding operations, fixture fabrication, production dependencies/public APIs, publication, provider promotion and earlier stopped packet retries.

**Health and constraints:** Metadata requests30 seconds, each response16MiB, each acquisition stage240 seconds, no more than64 package nodes. Native operations require a separately reviewed exact packet: at most3 attempts across this experiment, cumulative900 seconds, each command120 seconds, log16MiB, whole owned area plus temporary parent2GiB, each input16MiB, reviewed captures at most6144 inputs/640MiB per store, terminal preservation/retirement30 seconds. New bounds apply only to this independent experiment; no prior cap is reset. Explicit acquisition failures retain their original responses and at most3 evidence-driven repairs per distinct failure.

**Attributes:** Root is the sole writer and SDK/index owner; independent readiness and Oracle workers are read-only, with no recursive delegation. Native SDK work is serialized. Source/control/profile/index/336 ordinary binary identities are protected. **Users:** Maintainers deciding whether existing vector abstractions supply useful integration. **Runtime:** Private ignored evidence and a manifest-owned temporary directory, never a repository product/project output. **Beliefs and intent:** Declared package ranges and common source inheritance do not prove resolved compatibility; real compiler evidence is required before stronger claims.
